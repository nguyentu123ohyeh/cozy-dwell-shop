Cách dùng:
1. Copy emergency_fix_paul_lawrence_v2.py vào thư mục gốc project, ngang hàng với public.
2. Mở Terminal trong thư mục project.
3. Chạy: python emergency_fix_paul_lawrence_v2.py
   Nếu Windows không nhận python, chạy: py emergency_fix_paul_lawrence_v2.py
4. Mở trình duyệt, F12 > Console, chạy: localStorage.clear(); location.reload();

Script này có backup lần đầu trong thư mục _backup_before_paul_fix_v2.
